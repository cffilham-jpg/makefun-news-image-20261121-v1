A one-image front page summing up the world's news of **Saturday 21 November 2026**:
Russian missiles hit Poland; the World Court finds Myanmar committed genocide
against the Rohingya; Cyclone Akvan crosses India's Odisha coast; the Saudi-led
coalition intercepts Houthi missiles over Riyadh; US stocks fall sharply into
correction territory; and Trump, Xi and Putin wrap up their first trilateral
summit in Shenzhen.

The image is a 1024x1024 PNG rendered with PIL from a fresh script written for
this entry — six clear story panels under a masthead naming the day in large
type, designed to stay legible at about 300 pixels wide.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (byte-identical on every run)
```

## Files

- `main.py` — Python 3.13, standard library only; copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
- `entry.png` — the front-page image (1024x1024, under 1 MiB)
- `README.md`, `LICENSE` — this file and the MIT license
